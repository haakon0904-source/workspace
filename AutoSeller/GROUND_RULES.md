# AutoSeller - 프로젝트 그라운드 룰

최초 작성: 2026-04-26

---

## 프로젝트 정의

위탁판매 완전 자동화 에이전트.
한 번 셋업하면 사람 개입 0%. AI가 스스로 운영하는 무인 쇼핑몰 자동화 시스템.

---

## 핵심 전략

- 도매꾹, 오너클랜의 핫키워드 기반으로 상품 선별 (무분별 업로드 금지)
- 설정한 최소 마진율 이상인 상품만 업로드
- 하나의 프로그램에서 전 플랫폼 동시 업로드
- 유일한 사람 접점: 트위터(X) 등록 완료 알림

---

## 8단계 핵심 파이프라인

```
[스케줄러 - 자동 실행]
        ↓
① 키워드 데이터 수집
   - 소스: 도매꾹, 오너클랜, 네이버 데이터랩, 쿠팡 인기검색어
   - 계절/이슈 반영
        ↓
② AI 키워드 선정
   - Claude AI가 경쟁강도 + 검색량 기반 자동 스코어링
   - 이미 등록한 키워드 중복 제외
        ↓
③ 상품 자동 서치
   - 선정된 키워드로 도매꾹/오너클랜 자동 검색
   - 중복/불량 상품 자동 필터링
        ↓
④ 마진 계산
   - 공식: 판매가 - 도매가 - 플랫폼수수료 - 배송비 = 순이익
   - 마진율 = 순이익 / 판매가 × 100
   - 최소 마진율 기준 미달 → 자동 제외
   - 플랫폼별 수수료 각각 계산
        ↓
⑤ 상품 등록 + 하네스 검증
   - 상품 정보 DB 저장
   - Claude AI 하네스로 규약 검증
   - 실패 시 Claude AI 자동 수정 → 재시도 (최대 재시도 횟수 설정)
        ↓
⑥ 전 플랫폼 동시 업로드
   - 대상: 쿠팡, 네이버 스마트스토어, 11번가, 옥션, G마켓 등 가능한 전부
   - 플랫폼별 규격 자동 변환
   - 병렬 처리
        ↓
⑦ 등록 검증
   - 실제 플랫폼 노출 여부 확인
   - 가격, 이미지, 상품명 정상 여부 확인
   - 실패 항목 자동 재업로드
        ↓
⑧ 트위터(X) 알림
   - "오늘 N개 상품 등록 완료" 전송
   - 유일한 사람 접점
```

---

## 하네스 엔지니어링 원칙

- Claude AI 기반 자동 검증/수정 엔진
- **플러그인 방식**: 켜고 끌 수 있음
- **규약은 점진적 추가**: 지금은 빈 껍데기로 시작, 개발하면서 추가
- 하네스가 불필요하다고 판단되면 비활성화 가능
- 무한루프 방지: 최대 재시도 횟수 config로 설정

---

## 설계 원칙

1. **100% 자동**: 모든 단계 자동화. 사람 개입 없음
2. **Config 기반 운영**: 모든 운영 파라미터는 인풋값으로 관리 (언제든 변경 가능)
   - 실행 주기, 최소 마진율, 하루 최대 업로드 수, 재시도 횟수 등
3. **단계별 독립성**: 각 파이프라인 단계는 독립적으로 테스트/교체 가능
4. **오버엔지니어링 금지**: 필요할 때 분리. 미리 과설계하지 않음

```
│   ├── step6_upload.py
│   ├── step7_verify.py
│   └── step8_notify.py

│   ├── coupang.py
│   ├── smartstore.py
│   ├── elevenst.py
│   ├── auction.py
│   └── gmarket.py

├── db/                 # 상품 DB

    └── auto_seller_summary_session_N.md
```

## 기술 스택

| 역할 | 기술 |
|------|------|
| 백엔드/자동화 | Python |
| 크롤링 | Playwright |
| 데이터 처리 | pandas |
| DB | SQLite (로컬) or PostgreSQL |
| 스케줄링 | APScheduler |
| UI | Streamlit |
| AI 하네스 | Claude API (Anthropic) |
| 알림 | Twitter/X API |

---

## 단위 테스트 순서

기술적 가능 여부를 먼저 검증하는 것이 목표.

```
1순위 (쉬움)  : ④ 마진 계산 → ② AI 키워드 선정 → ⑧ 트위터 알림
2순위 (중간)  : ① + ③ 크롤링 → ⑤ 상품 등록 + 하네스
3순위 (어려움): ⑥ 플랫폼 업로드 → ⑦ 등록 검증
```

## 벤치마크 대상

- **사방넷**: 국내 1위 멀티채널 판매 관리
- **플레이오토**: 자동화 강점
- **셀링모어**: 위탁판매 특화
- **아이템스카우트**: 키워드 경쟁강도, 트렌드 분석
- **판다랭크**: 쿠팡 특화 키워드
- **태사자**: 추가 조사 필요

---

## 세션 관리 규칙

- 매 세션 종료 시 `session/` 디렉토리에 대화 기록 저장
- `auto_seller_all_session_N.md`: 전체 대화 누수 없이 저장
- `auto_seller_summary_session_N.md`: 요약 써머리 저장
- **"이전기억 복기"** 입력 시 → session 파일 읽고 컨텍스트 복원
