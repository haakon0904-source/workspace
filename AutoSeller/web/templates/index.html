파이프라인 동작 순서
1. 키워드 분석  →  파이프라인 실행 버튼을 누르면 네이버 쇼핑 인사이트 분석 결과가 아래에 펼쳐집니다. 상승률 상위 10개가 자동 선정되며, 원하지 않는 키워드는 제외하고 크롤링 시작을 누릅니다.
2. 도매꾹 수집  →  선택한 원본 키워드로 도매꾹 판매량순 크롤링. 판매가 · 이미지 · 상세 정보 수집.
3. 상품 필터  →  이미지 없음 / 도매가 3천원 미만·3만원 초과 / 최소구매수량 4개↑ / 정품·브랜드 포함 / 착불 → 자동 제외.
4. 마진 계산 + 검색태그  →  판매가×2.5배, 수수료+부가세 반영. 마진율 30% 미만 제외. 변형어를 쿠팡 검색태그로 추가.
5. DB 저장  →  통과 상품을 SQLite에 저장. 중복 상품 자동 스킵.
6. 쿠팡 업로드  →  쿠팡 WING API로 상품 등록 (변형어 검색태그 포함). 결과는 마진/상품 탭에서 확인.
