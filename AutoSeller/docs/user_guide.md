## 1. AutoSeller란?

AutoSeller는 온라인 위탁판매를 **자동화**하는 프로그램입니다.

### 기존 방식 vs AutoSeller

| 기존 방식 | AutoSeller |
|---|---|
| 도매 사이트를 직접 뒤져 상품 탐색 | 자동으로 상품 수집 |
| 엑셀로 마진 계산 | 자동 마진 계산 |
| 상품을 하나씩 쿠팡에 등록 | 자동 일괄 등록 |
| 판매 현황을 수동으로 확인 | 대시보드에서 한눈에 확인 |

### 동작 순서

```
도매꾹 상품 수집 → 마진 계산 → 쿠팡 자동 등록 → 대시보드 모니터링
```

## 2. 위탁판매 기초 개념

AutoSeller를 이해하기 위해 꼭 알아야 할 개념입니다.

### 위탁판매란?

내가 재고를 직접 보유하지 않고, **주문이 들어오면 그때 도매처에서 구매해서 고객에게 발송**하는 방식입니다.

```
고객 주문 → 내가 도매처에 주문 → 도매처가 고객에게 직접 배송
```

- **장점**: 재고 부담 없음, 초기 자본 적음
- **단점**: 마진이 낮음, 배송 품질 통제 어려움

### 핵심 용어

| 용어 | 설명 |
|---|---|
| **도매가 (매입가)** | 도매 사이트에서 내가 구매하는 가격 |
| **판매가** | 쿠팡에서 고객에게 파는 가격 |
| **수수료** | 쿠팡이 판매금액에서 떼가는 금액 (카테고리별 상이) |
| **부가세** | 세전 이익의 10% |
| **순이익 (마진)** | 내가 실제로 가져가는 돈 |
| **마진율** | 판매가 대비 순이익 비율 |

## 3. 시작 전 준비물

### 필수 계정

#### ① 도매꾹 계정
- 상품을 공급받는 도매 사이트
- 가입: [domeggook.com](https://domeggook.com)
- 무료 회원가입 후 바로 사용 가능

#### ② 쿠팡 WING 셀러 계정
- 상품을 판매할 플랫폼
- 가입: [wing.coupang.com](https://wing.coupang.com)
- 사업자등록증 필요 (개인사업자 가능)
- 가입 후 **판매자 승인**까지 수일 소요

#### ③ 쿠팡 Open API 키
WING 로그인 후 발급:
1. WING → 상단 메뉴 → **개발자센터**
2. **연동 정보 관리** → API 키 발급
3. **Access Key**와 **Secret Key** 복사해두기
4. **IP 화이트리스트**에 내 컴퓨터 IP 등록 필수
   - 내 IP 확인: [whatismyip.com](https://whatismyip.com)

> ⚠️ **중요**: IP가 바뀌면 (카페, 이동 등) WING에서 다시 등록해야 합니다.
> 집 와이파이 IP는 고정이 아니므로 변경 시마다 업데이트 필요.

### 필수 소프트웨어

#### Python 3.13 설치
1. [python.org](https://python.org) → Downloads → Python 3.13
2. 설치 시 **"Add Python to PATH"** 반드시 체크

#### 필요한 패키지 설치
터미널(Mac) 또는 명령 프롬프트(Windows)를 열고:

```bash
pip3 install flask playwright requests openpyxl
playwright install chromium
```

## 4. 최초 설치 및 설정

### 4-1. 인증 정보 설정

프로젝트 폴더 안에 `pw/pw.md` 파일을 만들고 아래 형식으로 저장:

```
도매꾹아이디
도매꾹비밀번호
Access Key: 쿠팡에서발급받은액세스키
Secret Key: 쿠팡에서발급받은시크릿키
```

> ⚠️ 이 파일은 절대 다른 사람과 공유하지 마세요. API 키가 유출되면 계정이 악용될 수 있습니다.

### 4-2. 키워드 및 카테고리 설정

`run_pipeline.py` 파일을 열어 판매할 상품 키워드를 설정합니다:

```python
KEYWORD_CATEGORIES = {
    "우산": {
        "display_category": 69884,        # 쿠팡 카테고리 코드
        "commission": ("패션", "패션잡화"), # 수수료 카테고리
    },
    # 새 키워드 추가 예시:
    "텀블러": {
        "display_category": 12345,         # WING에서 확인
        "commission": ("주방용품",),
    },
}
```

**카테고리 코드 찾는 법:**
1. WING → 상품관리 → 상품 등록
2. 카테고리 검색창에 키워드 입력
3. 카테고리 선택 후 브라우저 개발자도구(F12) → Network 탭에서 코드 확인

### 4-3. 마진 기준 설정

`run_pipeline.py`에서 아래 값을 조정합니다:

```python
CONFIG = {
    "sell_price_multiplier": 2.5,  # 도매가의 몇 배로 판매할지 (2.5 = 250%)
    "min_margin_rate": 0.2,        # 최소 마진율 20% 미만 상품은 제외
    "min_profit": 1000,            # 최소 순이익 1,000원 미만 상품은 제외
    "delivery_fee": 2500,          # 내가 부담하는 배송비
    ...
}
```

### 4-4. 쿠팡 반품지 정보 설정

```python
"coupang_return_address": {
    "name": "반품지 이름",
    "phone": "010-0000-0000",
    "zip": "우편번호",
    "address": "도로명 주소",
    "address_detail": "상세 주소",
},
```

## 5. 마진 계산 이해하기

AutoSeller는 아래 공식으로 마진을 계산합니다.

### 계산 공식

```
판매가    = 도매가 × 판매가 배수 (10원 단위 절사)
수수료    = 판매가 × 수수료율 (카테고리별 상이)
세전이익  = 판매가 - 도매가 - 배송비 - 수수료
부가세    = 세전이익 × 10%
순이익    = 세전이익 - 부가세
마진율    = 순이익 ÷ 판매가
```

### 예시 (도매가 5,120원짜리 상품)

| 항목 | 금액 |
|---|---|
| 도매가 | 5,120원 |
| 판매가 (×2.5배) | 12,800원 |
| 쿠팡 수수료 (10.5%) | 1,344원 |
| 배송비 | 2,500원 |
| 세전이익 | 3,936원 |
| 부가세 (10%) | 393원 |
| **순이익** | **3,543원** |
| **마진율** | **27.7%** |

### 수수료율 기준 (쿠팡)

주요 카테고리별 수수료율:

| 카테고리 | 수수료율 |
|---|---|
| 패션잡화 (우산, 모자 등) | 10.5% |
| 생활용품 | 7.8% |
| 뷰티 | 9.6% |
| 스포츠/레저용품 | 10.8% |
| 가전디지털 (기본) | 7.8% |
| 주방용품 | 10.8% |

> 전체 수수료 표: WING → 판매수수료 안내

## 6. 대시보드 사용법

### 대시보드 실행

터미널에서:

```bash
cd /Users/사용자이름/Workspace/AutoSeller
python3 web/app.py
```

브라우저에서 `http://localhost:5001` 접속

### 파이프라인 탭

![파이프라인 탭](파이프라인을 실행하고 실시간 로그를 확인하는 화면)

- **파이프라인 실행 버튼**: 클릭하면 상품 수집부터 쿠팡 등록까지 자동 실행
- **실시간 로그**: 각 단계별 진행 상황이 실시간으로 표시됨
- 실행 중에는 버튼이 비활성화되며 완료 시 자동 활성화

**로그 색상 의미:**
- 🔵 파란색: 단계 시작
- 🟢 초록색: 성공
- 🔴 빨간색: 실패

### 마진/상품 탭

#### 요약 카드

| 카드 | 설명 |
|---|---|
| 전체 상품 | DB에 저장된 총 상품 수 |
| 업로드 완료 | 쿠팡에 성공적으로 등록된 상품 수 |
| 평균 마진율 | 전체 상품의 평균 마진율 |
| 예상 총이익 | 모든 상품이 1개씩 팔릴 경우 이론상 총 순이익 |

#### 상품 목록

- **컬럼 클릭**: 해당 컬럼 기준으로 정렬 (한 번 더 클릭하면 역순)
- **검색**: 상품명으로 필터링

#### 쿠팡 상태 관리

1. **쿠팡 상태 동기화** 버튼 클릭
   - 쿠팡 API에서 실제 상태를 가져옴
   - 상품 수에 따라 10~30초 소요
2. 쿠팡 상태 컬럼에 드롭다운 표시
3. **판매중 → 판매중지** 선택 시 즉시 쿠팡에서 판매 중단

**쿠팡 상태 종류:**
| 상태 | 의미 |
|---|---|
| 승인완료 | 현재 판매 중 |
| 임시저장 | 판매 중지됨 |
| 심사중 | 쿠팡 검토 중 |

## 7. 파이프라인 실행하기

### 자동 실행 순서

#### Step 3: 도매꾹 상품 수집
- 설정한 키워드로 도매꾹을 자동 검색
- 상품명, 도매가, 이미지, 최소구매수량 등 수집
- 기본 2페이지 (페이지당 약 50개 상품)
- 네트워크 오류 시 3회 자동 재시도

#### Step 4: 마진 계산 및 필터링
- 각 상품의 판매가, 수수료, 부가세, 순이익 자동 계산
- 최소 마진율 미달 상품 자동 제외
- 최소 순이익 미달 상품 자동 제외

#### Step 5: DB 저장
- 마진 기준 통과 상품을 데이터베이스에 저장
- 이미 등록된 상품(중복)은 자동으로 건너뜀

#### Step 6: 쿠팡 등록
- 쿠팡 WING Open API로 상품 자동 등록
- 상품 이미지, 상세설명 자동 생성
- 등록 결과 (성공/실패) 로그에 표시

### 처음 실행 시 주의사항

1. **IP 확인**: 현재 내 IP가 WING 화이트리스트에 등록되어 있는지 확인
2. **계정 확인**: `pw/pw.md`에 도매꾹 로그인 정보가 정확한지 확인
3. **소량 테스트**: 처음에는 `max_pages: 1`로 설정해 소량만 테스트 권장

## 8. 상품 관리하기

### 판매중지 방법

1. 마진/상품 탭 → **쿠팡 상태 동기화** 클릭
2. 중지할 상품의 드롭다운에서 **판매중지** 선택
3. 즉시 처리됨 (쿠팡에서 약 10분 내 반영)

### 새 키워드 추가 방법

`run_pipeline.py`의 `KEYWORD_CATEGORIES`에 추가:

```python
KEYWORD_CATEGORIES = {
    "우산": { ... },
    "장갑": {                                    # 새로 추가
        "display_category": 99999,               # WING에서 확인한 코드
        "commission": ("패션", "패션잡화"),
    },
}
```

### 마진 기준 조정

수익성에 맞게 기준을 변경할 수 있습니다:

```python
"sell_price_multiplier": 3.0,   # 도매가의 3배로 판매 (기본값 2.5)
"min_margin_rate": 0.25,        # 최소 마진율 25%로 강화
"min_profit": 2000,             # 최소 순이익 2,000원으로 상향
```

## 9. 자주 묻는 질문 (FAQ)

**Q. 파이프라인 실행 중 "IP 오류" 가 나옵니다.**
A. 쿠팡 WING → 개발자센터 → 연동 정보 관리에서 현재 내 IP를 다시 등록하세요. IP 확인: [whatismyip.com](https://whatismyip.com)

---

**Q. 상품이 수집되는데 DB에 저장이 안 됩니다.**
A. 마진 기준에 미달한 상품이 모두 걸러진 것입니다. `min_margin_rate`나 `min_profit` 값을 낮춰보세요.

---

**Q. 쿠팡 등록은 됐는데 상품이 안 보입니다.**
A. 쿠팡 심사 중입니다. 보통 1~2시간 내 승인됩니다. WING → 상품관리에서 상태를 확인하세요.

---

**Q. 같은 상품을 또 실행하면 중복 등록되나요?**
A. 아닙니다. 상품번호(item_no) 기준으로 중복 체크하여 이미 등록된 상품은 건너뜁니다.

---

**Q. 주문이 들어오면 어떻게 하나요?**
A. 현재 버전은 상품 등록까지만 자동화됩니다. 주문이 들어오면 도매꾹에서 수동으로 구매 후 고객 주소로 배송을 요청해야 합니다. (향후 주문 자동화 기능 추가 예정)

---

**Q. 어떤 상품이 잘 팔리나요?**
A. 계절 상품, 생활필수품, 검색량이 높은 키워드 상품이 유리합니다. 경쟁이 너무 치열한 카테고리는 피하고, 마진율 25% 이상을 목표로 하세요.

---

**Q. 파이프라인을 자동으로 매일 실행할 수 있나요?**
A. 현재는 대시보드에서 수동 실행합니다. Mac의 `crontab` 또는 Windows의 작업 스케줄러로 자동 실행 설정이 가능합니다. (향후 스케줄러 기능 추가 예정)
