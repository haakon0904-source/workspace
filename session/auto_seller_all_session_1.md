```

        ↓
```

주요 기능:
① 키워드 트렌드 수집: 도매꾹, 오너클랜 핫키워드, 네이버/쿠팡 크로스 체크
② 상품 선별 엔진: 핫키워드 매칭, 마진율 자동 계산, 경쟁 강도 분석
③ 상품 등록: 플랫폼별 규격 자동 변환
④ 전 플랫폼 동시 업로드: 쿠팡, 스마트스토어, 11번가, 옥션, G마켓 등

**User**: 1번 둘다. 자동 먀. 3번 마진관리도 프로그램. 그래서 특정 마진이 이상이 아니면 업로드 안함.

**Assistant**: AutoSeller 시스템 설계:

```
[도매꾹 + 오너클랜]
    ↓ 핫키워드 자동 수집
[키워드 분석 엔진]
    ↓ 키워드 매칭 상품 필터링
[마진 계산 엔진]
    ↓ 마진 X% 이하 → 자동 제외 / 마진 X% 이상 → 통과
[상품 DB]
    ↓ 플랫폼별 규격 자동 변환
[동시 업로드] → 쿠팡 / 스마트스토어 / 11번가 / 옥션 / G마켓 ...
```

기술 스택: Python / Playwright / pandas / SQLite or PostgreSQL / APScheduler / Streamlit / 각 플랫폼 공식 API

마진 공식: 판매가 - 도매가 - 플랫폼수수료 - 배송비 = 순이익 / 순이익 / 판매가 × 100 = 마진율(%)
