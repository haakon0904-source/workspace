# AutoSeller - 요약 써머리 Session 1

날짜: 2026-04-26

---

## 프로젝트 한줄 정의

AI가 운영하는 위탁판매 완전 자동화 에이전트. 사람 개입 0%, 트위터 알림만 수신.

---

## 확정된 8단계 파이프라인

① 키워드 데이터 수집 (도매꾹 + 오너클랜 + 네이버/쿠팡)
② AI 키워드 선정 (Claude AI 스코어링, 경쟁강도+검색량 기반)
③ 상품 자동 서치 (키워드 기반 도매 사이트 크롤링, 중복/불량 필터)
④ 마진 계산 (기준 미달 자동 제외, 플랫폼별 수수료 각각 계산)
⑤ 상품 등록 + 하네스 (Claude AI 자동 검증/수정/재시도)
⑥ 전 플랫폼 동시 업로드 (쿠팡, 스마트스토어, 11번가, 옥션, G마켓 등, 병렬 처리)
⑦ 등록 검증 (노출/가격/이미지 확인, 실패 시 자동 재업로드)
⑧ 트위터 알림 ("오늘 N개 상품 등록 완료")

---

## 핵심 설계 원칙

- **100% 자동**: 모든 단계 자동, 사람 개입 없음
- **키워드 기반**: 핫키워드 기반 스마트 선별. 무분별 업로드 금지
- **마진 필터**: 설정한 최소 마진율 이상만 업로드
- **하네스**: Claude AI 기반 플러그인 방식. 규약은 점진적 추가. 불필요하면 비활성화 가능
- **config 관리**: 모든 운영 파라미터는 인풋값으로 관리 (실행주기, 마진율, 재시도횟수 등)
- **오버엔지니어링 금지**: 필요할 때 분리. 미리 과설계 금지

---

## 확정된 디렉토리 구조

```
autoseller/
├── GROUND_RULES.md     # 프로젝트 그라운드 룰
├── pipeline/           # 8단계 파이프라인 (step1~step8)
├── uploader/           # 플랫폼별 업로더 (coupang, smartstore, elevenst 등)
├── harness/            # Claude AI 검증/수정 엔진
├── db/                 # 상품 DB
├── config/             # 운영 파라미터 관리
├── scheduler/          # 전체 파이프라인 자동 실행
└── session/            # Claude와의 대화 기록
```

- crawler/ 디렉토리는 제거 결정 (오버엔지니어링, 중복 발생 시 그때 분리)

## 기술 스택

Python / Playwright / pandas / SQLite or PostgreSQL / APScheduler / Streamlit / Claude API / Twitter API

---

## 단위 테스트 순서

```
1순위 (쉬움)  : ④ 마진계산 → ② AI키워드선정 → ⑧ 트위터알림
2순위 (중간)  : ① + ③ 크롤링 → ⑤ 하네스
3순위 (어려움): ⑥ 플랫폼 업로드 → ⑦ 등록 검증
```
